# Python desde JS/TS

Notas curtas de quem já programa em JavaScript e TypeScript.

Os três drills que abrem o fork de ingestão:

1. Imprimir o número de páginas de um PDF.
2. Quebrar texto em janelas de 1000 caracteres com overlap de 150, com teste.
3. Uma CLI que recebe o caminho do arquivo.

Conceitos que entram quando o código pede: ambiente virtual, função pura, type hints com Pydantic, `async def`, `asyncio.gather` e `Protocol`.

A anotação de tipo em Python não impede o programa de rodar. Na borda, o Pydantic faz o papel do Zod.
