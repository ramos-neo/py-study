# Data Engineering

Notas da prova Professional Data Engineer, no Google Cloud. Cada fase da Izify ganha um parágrafo ligando a peça local ao serviço.

| Peça local | Tema da prova |
| --- | --- |
| Ingestão idempotente por hash | Batch e retry sem duplicar |
| Embeddings em lote | Processamento e custo |
| Postgres, HNSW e busca textual | Armazenamento e índice |
| Troca do modelo de embedding | Migração de schema |
| Papéis de escrita e de leitura | Privilégio mínimo |
| Relatórios do RAGAS | Dado analítico |
| Reindexação agendada | Orquestração |
| Máscara de CPF no trace | Dado sensível |

Cloud Run, Cloud SQL, Vertex AI e Secret Manager ficam para janeiro. O corte de dezembro está em `openspec/changes/hub-estudo-izify/design.md`.
